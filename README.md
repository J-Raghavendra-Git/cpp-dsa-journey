## About

This repository is a structured record of my ongoing journey to master C++ and Data Structures & Algorithms. It contains implementations, practice solutions, learning notes, and progressively challenging exercises designed to strengthen algorithmic thinking and software engineering fundamentals.

The focus is not only on solving problems, but also on writing clear, maintainable code and understanding the trade-offs behind each solution.

## Objectives

- Build strong C++ programming fundamentals
- Master essential data structures and algorithms
- Improve time and space complexity analysis
- Develop reliable problem-solving habits
- Write clean, readable, and efficient code
- Prepare for technical interviews and real-world software development

## Features

- Topic-based C++ implementations
- Fundamental data structures built from scratch
- Algorithm implementations with complexity analysis
- Practice problems and reusable patterns
- Progressive learning roadmap
- Consistent documentation of learning progress
- Interview-oriented problem-solving practice

## Topics Covered

## Learning Workflow

1. Understand the problem and constraints.
2. Identify the appropriate data structure or algorithm.
3. Implement a clear baseline solution.
4. Analyze time and space complexity.
5. Test edge cases and improve the implementation.
6. Record the key insight for future revision.

## How to Run

Clone the repository and compile any C++ source file with a C++17-compatible compiler:

```bash
git clone https://github.com/J-Raghavendra-Git/cpp-dsa-journey.git
cd cpp-dsa-journey

g++ -std=c++17 -Wall -Wextra -pedantic path/to/file.cpp -o solution
./solution
```

On Windows, run the generated executable as `solution.exe`.
